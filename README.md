## 🌟 Overview

**Aura Wealth** is an interactive, browser-based financial modeling sandbox designed for scenario planning, net worth tracking, debt payoff strategy modeling, and FIRE (Financial Independence, Retire Early) forecasting. 

It features zero-delay client-side state management, rich Chart.js visualizations, persona-based financial diagnostics, and seamless integration with **[Ambulkar Cortex AI Gateway](https://github.com/Hitesh-15/Cortex-AI-search)**.

---

## ✨ Key Features

- 💼 **Net Worth & Ledger Tracker:** Real-time asset & liability balancing, liquidity ratio calculation, and net worth growth tracking.
- ⚡ **FIRE (Financial Independence) Calculator:** Interactive Trinity Study 4% Rule scenario simulator with inflation adjusting, real return modeling, and retirement age forecasting.
- ⚔️ **Debt Payoff Strategist:** Compare **Debt Avalanche** (highest APR first) vs **Debt Snowball** (lowest balance first) side-by-side with interest savings projections.
- 🎭 **Advisor Persona Switcher:** Switch live between 4 distinct advisor strategies:
  - ⚖️ **Balanced Wealth Growth** (Steady index growth & 3-6mo emergency buffer)
  - ⚡ **Aggressive FIRE Coach** (Tax-advantaged account maxing & rapid retirement timeline)
  - 🛡️ **Wealth Preservation** (Capital protection, high-yield cash & inflation hedging)
  - ⚔️ **Debt Crusader** (Aggressive interest elimination & cash flow unlocking)
- 🧠 **Ambulkar Cortex AI Gateway Integration:** Anonymizes queries locally (zero private bytes sent) and dispatches strategy questions directly to Ambulkar Cortex Neural Gateway with deep web research launchers.
- 💾 **JSON Data Export/Import:** Full data portability with local JSON backup and restore capabilities.
